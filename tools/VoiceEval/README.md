# VoiceEval

録音した声に環境音を混ぜ、ゲームと同じ 60 fps の呼び出しを再現して、音声コマンド認識 (`Source/Voice/`) を評価する CLI ツール。

## 用意するもの

### 声のコーパス

| フォルダ               | 録音した人 |
| ---------------------- | ---------- |
| `corpus/twosquirrels/` | りすりす   |

ブラウザーで `tools/voice-recorder.html` を開けば録音できる。

### 環境音

参加者の会話が入っているためリポジトリには含めていないが、traPcloud の `部内共有/event/1-Monthon/24/02/音声解析用/会場環境再現用_合宿BBQ環境音.m4a` を以下のコマンドで 48 kHz モノラルの WAV に変換するとよい。

```sh
ffmpeg -i 会場環境再現用_合宿BBQ環境音.m4a -ac 1 -ar 48000 -c:a pcm_s16le ambience.wav
```

前半をキャリブレーションに、後半を評価に使う。

## 実行

```sh
VoiceEval.exe <コーパスのフォルダ> <環境音の WAV> <出力フォルダ> [key=value ...]
```

- Release の Siv3D は作業ディレクトリを exe の場所に移すので、パスは絶対パスで渡す
- エラーは `<出力フォルダ>/error.txt` に書かれる。Siv3D のダイアログが出ることもあるので、自動で回すときは時間制限を付ける
- 全条件・キャリブレーション 3 回分で、雑音抑制なしは約 1 分、雑音抑制ありは約 40 分 (Core i7-9700)
- ゲームは雑音抑制をかけるが、評価ツールの既定では抑制しない。ゲームと同じにするときは `denoise=<リポジトリ>/models/rnnoise.bin` を渡す。

## 設定

`key=value` で渡す。省略したときの値は、評価用のもの以外はゲームの既定値と同じ。

| key                   | 既定値         | 内容                                                                                                    |
| --------------------- | -------------- | ------------------------------------------------------------------------------------------------------- |
| `takes`               | `1,2,3`        | キャリブレーションに使う母音の録音の回。残りの回で母音を評価する                                        |
| `conditions`          | 全部           | 評価する条件 (`clean,snr30,snr20,snr10,snr5,snr0`)                                                      |
| `mode`                | `all`          | `vowels` は母音だけ評価する。`dump` / `mfcc` は `frames.csv` / `mfcc.csv` を書き出す                    |
| `denoise`             | なし           | RNNoise の重みのパス。指定すると混ぜた音声を雑音抑制してから解析する                                    |
| `drymix`              | `0.1`          | 雑音を抑制した音声に、抑制前の音声を混ぜる割合 (`denoise` より後に書く)                                 |
| `gate`                | `1.25`         | 入力感度を、キャリブレーション用の環境音の 20 ms 音量の 95 パーセンタイルの何倍に合わせるか (最低 0.01) |
| `silence` / `vowel`   | `1.5`          | 無音 / 母音を何秒ぶん登録するか                                                                         |
| `k`                   | `11`           | k-NN の k (0 なら登録の平均との距離)                                                                    |
| `distance`            | `cosine`       | `cosine` か `euclidean`                                                                                 |
| `standardize`         | `true`         | ユークリッド距離を測る前に、各次元を登録の分散で正規化する                                              |
| `fmin` / `fmax`       | `150` / `8000` | メルフィルタの周波数の範囲 (Hz)                                                                         |
| `mel`                 | `20`           | メルフィルタの帯域数                                                                                    |
| `order`               | `12`           | MFCC の次数                                                                                             |
| `preemph`             | `0.97`         | 高域強調の係数                                                                                          |
| `margin`              | `10`           | 入力感度の閾値より何 dB 大きければ、無音や息に分類しないか                                              |
| `end`                 | `18`           | 発話が終わったとみなして判定する無音の長さ (フレーム)                                                   |
| `early` / `earlythr`  | `4` / `0.3`    | 早めに判定する無音の長さ (フレーム) と、そこで発動するコストの上限                                      |
| `merge`               | `30`           | 発動しなかった発話に、後の発話をつなげられる無音の長さ (フレーム)                                       |
| `cooldown`            | `30`           | 発動してから次の発話を聞き始めるまでのフレーム数                                                        |
| `minvoiced`           | `4`            | 発話とみなす最小の有声フレーム数                                                                        |
| `minvowel` / `mingap` | `3` / `2`      | 母音 / 無声子音の無音が続く最小のフレーム数                                                             |
| `filler`              | `1.5`          | 母音と母音の間の、どの母音にも当てはめないフレームのコスト                                              |
| `transition`          | `0.5`          | 母音の移り変わりの途中の母音のフレームに加えるコスト                                                    |
| `thr`                 | `0.7`          | 1 フレームあたりの平均コストがこれ以下なら発動する                                                      |
| `ambiguity`           | `0`            | 別の行動のコマンドとのコストの差がこれ未満なら発動しない                                                |
| `longer`              | `0.05`         | 長いコマンドを優先する、コストの差の許容量                                                              |

## 出力

| ファイル                                    | 内容                                                                   |
| ------------------------------------------- | ---------------------------------------------------------------------- |
| `results.csv`                               | 条件・キャリブレーションの回・キャラクターごとの成績                   |
| `lines.csv`                                 | コマンドと読み方ごとの正解・取り違えの数                               |
| `detections.csv`                            | 録音 1 本ごとの、期待する行動と発動した行動 (`行動@発話開始からの ms`)。どのコマンドにも当てはまらなかった発話は `?@ms` |
| `vowel_confusion.csv`                       | 母音の混同行列                                                         |
| `frames.csv`                                | `mode=dump` のときの、フレームごとの音素スコア                         |
| `mfcc.csv`                                  | `mode=mfcc` のときの、母音とコマンドの MFCC、`VowelColor` の色、音量   |
| `options.txt` / `progress.txt` / `done.txt` | 渡した設定、途中経過、所要時間                                         |

### 指標

- `vowel_accuracy`: 母音の録音の発話部分で、推定の最大の音素の母音が正しいフレームの割合
- `noise_as_vowel`: 環境音だけの 30 秒で、母音と推定したフレームの割合
- コマンドの録音とコマンドでない声をランダムな間隔で並べ、ユウカ (`yuuka`) とアイリ (`airi`) のそれぞれで判定させる
  - `hit`: 発話開始から発話終了 0.8 秒後までに、正しい行動が最初に出た数 (行動単位。ガード/守れ、壊せ/刺せは同じ扱い)
  - `wrong`: 最初に出た行動が違った数
  - `false_by_speech` / `false_by_noise`: コマンドでない声・他キャラのコマンド・2 回目以降の発動 / 発話の無い区間での発動
  - `latency_median_ms`: 正解の発動が発話終了からどれだけ後か (負なら発話中)
- SN 比は、コマンドの録音の発話部分の音量の中央値を声の大きさとして、環境音の音量を合わせる
